## Tolerances (why not bitwise everywhere)
* Rotation composition: angles are computed in float32 by ComfyUI's `rope()`; |pos·ω| up to ~70 rad → ~5e-5 absolute.
* Patched attention vs float64 oracle and vs QIE-native: different summation order of SDPA/einsum in float32, 2e-5.
* Runtime LoRA vs LoraLoader: the merged path rounds the patched weight once; the runtime path recomputes it each
  forward in float32 — identical formula, ≤ 2e-5 after 3 sampler steps.
* Batched vs separate cond/uncond: different matmul batch shapes, 1e-5.
* "Disabled" settings are **bitwise** (torch.equal) everywhere because they short-circuit to the unpatched call.
